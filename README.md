### ALGO-000148: Simultaneously small and balanced planar BSPs
- **Subfield:** Computational geometry
- **Open:** Construct binary space partitions for \(n\) disjoint planar line segments with optimal \(O(n\log n/\log\log n)\) size and \(O(\log n)\) height simultaneously.
- **Status:** Optimal size without the balancing requirement is known. The combined size–height target remains open.
- **Type:** theory
- **Why:** Small structures save memory, while balanced structures support fast queries.
- **Key works:** Paterson and Yao (1990), *Efficient Binary Space Partitions for Hidden-Surface Removal and Solid Modeling*; Tóth’s optimal-size work; TOPP Problem 14.
- **Related:** Computer graphics—visibility acceleration structures.
